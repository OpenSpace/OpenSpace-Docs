# Profile Addons

Addons are bundles of assets designed to add specific content to a profile.
A profile may include one or more addons, selected at startup from the launcher.

## Recommended Addons
Each profile includes a set of recommended addons chosen by the profile's author. You can select any combination at startup, but the recommended set is a good place to start.

## Available Addons
Below are examples of available addons, typically recommended for the Default profile. For the full list, see the Addons dropdown in the launcher. Hovering over an addon in the launcher will show a description of its contents.

  - [Asteroids](asteroids): Adds a collection of asteroids in the Solar System, including the asteroid belt, near-Earth objects, and more.
  - Dwarf Planets: Adds a collection of dwarf planets in the Solar System.
  - Interstellar Objects: Adds a collection of interstellar objects that have been observed passing through the Solar System.
  - Minor Moons: Adds the discovered minor moons for the outer planets in the Solar System. Per default, just the major moons are included in the Solar System content.
